# Build assumptions

1. The repository is new and independent from the Denver 2024 repository.
2. The primary users are technical sellers, solution architects, automation specialists, and POV sponsors.
3. GitHub or an equivalent governed Git service will host the library.
4. A short-link service will be selected later; this repository defines the redirect contract but does not provision infrastructure.
5. RHEL patch content comes from an approved customer source such as Red Hat Satellite; the demo does not emulate Satellite APIs.
6. ServiceNow and CMDB integration are adapter contracts. The safe demo writes local evidence rather than calling live systems.
7. AAP coordinates the workflow; platform-native tools keep execution ownership where appropriate.
8. Sample timings and thresholds are illustrative until replaced by customer measurements.
9. Source decks are references, not redistributed assets. Internal or confidential markings remain controlling.
10. No claim of product certification or support is made for customer-developed content in this library.
