# Metrics-Based Process Mapping

This adaptation follows the Open Practice Library's [Metrics-Based Process Mapping](https://openpracticelibrary.com/practice/metrics-based-process-mapping/) concept: map detailed process steps with actors, time, resources, and quality so improvement can be measured.

## Minimum fields per step

| Field | Definition |
|---|---|
| Step | Verb-object action |
| Actor | Role doing or deciding the work |
| System | Tool where work or evidence lives |
| Process time | Hands-on time spent doing the step |
| Wait time | Time queued or waiting between actions |
| Resources | People or systems required |
| Percent complete and accurate | Share of incoming work usable without correction or clarification |
| Rework | Frequency and typical time |
| Evidence | Observable source for the measure |

## Workshop

1. Agree on start and acceptance boundaries.
2. Map the most common current path.
3. Add actors, tools, handoffs, decisions, and exceptions.
4. Estimate ranges if exact data is unavailable.
5. Mark each estimate as hypothesis.
6. Select obtainable evidence and an observation window.
7. Calculate total process time, wait time, lead time, and rolled quality.
8. Identify the constraint rather than optimizing every step.
9. Design a future state and decide what will be remeasured.

## Metric formulas

- Lead time = elapsed time from accepted request to accepted service.
- Process time = sum of hands-on step time.
- Wait time = lead time minus process time.
- Flow efficiency = process time divided by lead time.
- Rolled complete and accurate = product of each step's complete-and-accurate rate.

Use customer observations for decisions. Illustrative values are teaching aids only.
