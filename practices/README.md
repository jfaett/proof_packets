# Practice catalog

Practices are reusable ways of working. A Proof Pack selects only the practices needed to create trustworthy artifacts.

| Practice | Produces | Used in stage |
|---|---|---|
| [Discovery](discovery.md) | Outcome, stakeholders, assumptions, decision | Discover |
| [SOP capture](sop-capture.md) | Validated current procedure and exceptions | Understand / Map |
| [Metrics-Based Process Mapping](metrics-based-process-mapping.md) | Current-state flow and baseline | Understand / Map, Baseline |
| [Decomposition](decomposition.md) | Human, automation, reusable, and gap classification | Decompose |
| [Proof design](proof-design.md) | Hypothesis, measures, evidence, decision rule | Prove |
| [ReCommoning](recommoning.md) | Shared capability proposal and stewardship | Expand |

These adaptations point to the [Open Practice Library](https://openpracticelibrary.com/) where relevant but are written specifically for a sales proof motion.
