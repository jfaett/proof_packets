# RHEL patching demo

This is a safe-by-default demonstration of the capability and evidence flow.

## Modes

- **Simulation** — default; runs locally, changes no packages or services, writes only redacted JSON evidence under demo/evidence.
- **Live reference path** — disabled until the customer adapts inventory, approval, readiness, content, application, credentials, recovery, and evidence contracts and sets two explicit gates.

Start with [setup](setup.md), then use the [talk track](talk-track.md) and [expected results](expected-results.md).

The demo is intentionally transparent. It is designed to expose decisions, contracts, evidence, and failure handling—not to impersonate a production patch system.
