# Release and versioning

The repository and every Proof Pack use semantic versioning.

- **Major** — contract, safety, evidence, or deep-link behavior breaks.
- **Minor** — backward-compatible capability, pack, or evidence improvement.
- **Patch** — correction with no contract change.

## Release record

Each release records:

- version and date;
- affected use cases and capabilities;
- migration or rollback notes;
- test evidence;
- approving owners;
- known limitations.

Workflow execution evidence should record repository commit, pack version, and relevant capability versions. Retire stale versions deliberately; do not silently overwrite approved content.
