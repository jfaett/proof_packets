# Maturity model

| Level | Meaning | Required proof |
|---|---|---|
| Draft | Structure or content incomplete | Owner and scope only |
| Demonstrable | Safe repeatable demo exists | Setup, reset, expected results, demo test |
| Reference | Complete reusable pack | v1.0 DoD, owners, contract tests |
| Proven local | A specific customer validated agreed outcomes | Evidence remains in approved customer system, not this repository |
| Retired | No longer recommended | Reason, date, successor, retained history |

Maturity is not a marketing score. It describes evidence and stewardship. A proven-local pack does not imply universal results.
