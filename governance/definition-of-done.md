# Definition of done

A Proof Pack is reference-ready only when:

- all v1.0 required artifacts exist;
- illustrative content and customer unknowns are unmistakable;
- the manifest validates and capability references resolve;
- current and future state share the same boundaries;
- metric definitions, sources, windows, and owners are explicit;
- the safe demo is reproducible by another SA;
- the live path requires explicit authorization;
- at least one failure path is demonstrated;
- evidence links to workflow and content version;
- source provenance is recorded;
- owners accept maintenance;
- short links resolve;
- changelog and semantic version are current.

A capability is shared-ready only when its contract, supported targets, failure semantics, evidence, owner, tests, version, and consumers are documented.
