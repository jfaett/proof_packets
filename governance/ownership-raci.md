# Ownership and RACI

| Activity | Service owner | Automation content owner | Platform owner | Evidence owner | Security/change | Consumer |
|---|---|---|---|---|---|---|
| Define outcome and acceptance | A | C | C | C | C | R |
| Design orchestration | C | R | C | C | C | C |
| Maintain shared capability | C | A/R | C | C | C | C |
| Operate AAP controls | C | C | A/R | C | C | I |
| Approve live scope | A | C | C | C | R | I |
| Collect and retain evidence | C | C | C | A/R | C | I |
| Accept proof result | A/R | C | C | C | C | C |
| Retire content | A | R | C | C | C | I |

A = accountable, R = responsible, C = consulted, I = informed.

Every pack replaces role placeholders with named teams before operational use.
